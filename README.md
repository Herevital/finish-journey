# השעון של כליל 🕐

אפליקציה ויזואלית וחמודה שנועדה ללמד ילדים בגיל הגן לקרוא שעון מחוגים (אנלוגי), נבנתה במיוחד עבור כליל (גיל 5.5).

## איך מפעילים?
פשוט פותחים את הקובץ `index.html` בכל דפדפן (מחשב, טאבלט או טלפון). אין צורך בהתקנה.

## מה יש באפליקציה?
- **📖 בואי נלמד** – שעון גדול וברור עם מספרי הדקות. אפשר לסובב את המחוגים קדימה/אחורה ולחצי שעה, והאפליקציה מקריאה בקול את השעה בעברית.
- **🎮 מה השעה?** – משחק שאלות: מציג שעון וצריך לבחור את התשובה הנכונה מבין 4 אפשרויות. אוספים כוכבים ⭐ ומקבלים קונפטי 🎉.
- **🖐️ סובבי את השעון** – משחק הפוך: מקבלים שעה וצריך לסובב את מחוגי השעון עד שיתאימו.

## עקרונות לימודיים
- מתחילים משעות עגולות בלבד, וחצאי שעות מתווספים בהדרגה.
- משוב מיידי בקול, בצבע ובאנימציה מחזק למידה.
- מחוג השעות (ורוד, קצר) ומחוג הדקות (סגול, ארוך) נבדלים בבירור בצבע ובאורך.

## טכנולוגיה
קובץ HTML יחיד, ללא תלות חיצונית. משתמש ב-Web Speech API להקראה בעברית וב-Web Audio API לצלילי עידוד. הכוכבים שנאספו נשמרים בדפדפן.
